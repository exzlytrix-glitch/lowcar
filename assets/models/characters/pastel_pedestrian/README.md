# Pastel cube pedestrian

One friendly, blank-faced cube humanoid, 1.68 m tall, entirely pastel lavender (`#B7A5DB`). A single material, no textures, and 528 triangles. One-facet edges soften the blocks without rounding away their cube silhouette.

`pastel_pedestrian.glb` imports with one skinned mesh and an 11-bone hierarchy. The Blender source retains 12 editable blocks with rigid bone weights for future animation. No animations or pedestrian behavior are included in this model pass.

Ground-centered origin; faces Godot +Z. The reusable scene is `res://scenes/characters/pastel_pedestrian.tscn`. Double-click **Review Pedestrian.command** at the project root for the model view.

Rebuild: `/Applications/Blender.app/Contents/MacOS/Blender --background --python tools/build_pedestrian.py`.
