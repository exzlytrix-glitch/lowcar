# Lowcar — building batch 23

Courtyard Shopping Centre (092), Neighborhood Bank (093), Corner Clinic (094), Hardware Superstore (095). Approved pastel French Quarter style, chunky cream trim, recessed blue glass, broad neighborhood proportions.

Placement scenes: `scenes/buildings/batch_23/`. Meters, ground-center origins, Godot +Z front, one static visual mesh per building. Bank piers collide, and the hardware shed and office have separate boxes. Editable Blender sources: `source/`.

Included in the city after relaunch. Review: `scenes/review/building_batch_23.tscn`; 0 for all, 1–4 select, drag to orbit, wheel to zoom. Preview: `previews/lineup.png`. Rebuild: `tools/build_building_batch_23.py`.
